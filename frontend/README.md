# FUNDRYX Frontend Client Application

High-performance institutional decentralized finance web portal built with React 19, Vite, Tailwind CSS v4, and Ethers.js.

## Key Features

- **Able Credit Terminal**: Algorithmic borrow & supply interface with per-second interest compounding.
- **Borderline Verify**: Deterministic credit scoring (0–850) and zero-knowledge solvency verification.
- **AI Risk Telemetry Sentinel**: Real-time multi-node quorum consensus monitoring.
- **Capital Markets**: Federated multi-currency liquidity vaults (USDC, EURC, FDX).
- **Leganetum Governance**: Smart legal contracts and institutional compliance covenants.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
